# Odin Sign-Up Form

An HTML and CSS project that develops a sign up web form.

## Description

[Odin Sign-Up Form](https://www.theodinproject.com/lessons/node-path-intermediate-html-and-css-sign-up-form) is the first project in the full-stack JavaScript portion of the [Odin Project](https://www.theodinproject.com/paths)
designed to give learners an opportunity to apply intermediate HTML and CSS concepts. In the project, you will find an HTML file that creates the entire DOM of the sign-up form and a CSS file that styles the web page using Flexbox. The primary new topics covered in this project, compared to previous ones, are HTML form validation and user feedback through CSS styling in response to user interactions and invalid input using pseudo-classes.
